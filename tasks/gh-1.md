# Задача
Нужно написать веб-приложение которое будет принимать на вход url, а на выходе давать информацию о теге head сайта.

# Стек
Фреймворк: Rust + Topcoat (modular fullstack-фреймворк от tokio-rs, построен на Axum)
> ⚠️ Topcoat на ранней стадии (experimental), возможны breaking changes. Актуальная версия 0.6.2 (использована в этой задаче).

# Интерфейсы
* html на основе htmx — в Topcoat реализуется серверным рендерингом через `view!`-макрос и файловую маршрутизацию (`#[page]`, `#[component]`, `#[layout]`)
* REST api

# Принцип работы
Приложение берёт url и извлекает тег head.
Пользователю предоставляются:
* url
* Расшифровка url: схема, хост, порт, путь, параметры и их значения
* отформатированное содержимое тега head с отступом 2 пробела
* заголовок (тег <title>)
* описание (meta description)
* seo-данные: canonical, robots, keywords
* opengraph-данные: og:title, og:description, og:image, og:url, og:type, og:site_name
* список favicon (размер, url)

# html
## UI
Topcoat UI (feature `ui`). DaisyUI использовать только если элемент интерфейса нельзя реализовать средствами Topcoat UI — в идеале DaisyUI не должен использоваться вообще.

## Страницы
### Страница ввода url
Одно поле ввода и кнопка по центру экрана

### Страница результата
Состоит из следующих блоков:
* Строка с полным url
* Блок поделённый на две части в пропорции 1:3
    * Расшифровка url
    * Блок с двумя вкладками
        * Информация из тега head
        * Отформатированный тег head

# API
API должен отдавать всю информацию перечисленную в "Принцип работы".

## Endpoint
`GET /api/head?url=<url>`

## Ответ
```js
response = {
  url: "...",                      // полный url
  parsed_url: {                    // Расшифровка url
    scheme: "...",                 // схема
    host: "...",                   // хост
    port: 80,                      // порт
    path: "/",                     // путь
    query: { "key": "value" }      // параметры и их значения
  },
  title: "...",                    // заголовок (тег <title>)
  description: "...",              // описание (meta description)
  seo: {
    canonical: "...",              // <link rel="canonical">
    robots: "...",                 // <meta name="robots">
    keywords: "..."                // <meta name="keywords">
  },
  opengraph: {
    title: "...",                  // og:title
    description: "...",            // og:description
    image: "...",                  // og:image
    url: "...",                    // og:url
    type: "...",                   // og:type
    site_name: "..."               // og:site_name
  },
  favicons: [
    { url: "...", size: "32x32" }  // url и размер favicon
  ],
  head: "<head>...</head>"         // отформатированный тег head, отступ 2 пробела
}
```

## Favicon
* Включаются все `<link>`, где `rel` содержит `icon` или `apple-touch-icon`.
* Размер берётся из атрибута `sizes`; если `sizes` нет — скачать favicon и определить фактические размеры.

## Ошибки
* `400` — невалидный url
* `502` — сайт недоступен (таймаут/сеть)

Тело ошибки: `{"error": "..."}`
